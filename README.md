## ✨ 功能

1. **按课表全自动守候**
   - 每节课开始前自动在后台拉起 Edge 签到页准备；
   - 自动接入该教室对应的智慧教室直播间，实时抓取课堂语音字幕；
   - 字幕中出现 4 位签到码候选时，毫秒级自动在后台完成签到；
   - 上课期间每 45 分钟自动刷新保活签到页，下课后自动收尾待机。

2. **可视化手动模式**
   - 粘贴任意教室的超星直播间链接 → 点【▶ 开始监听此直播间】→ 界面立即滚动显示该课堂实时字幕；
   - 一键【检查登录认证】【退出认证(清空登录)】【测试输入 1234】。

3. **课表与教室链接管理**
   - 内置浙财标准作息（第 1–14 节），可直接按节次排课；
   - 维护各教室（9107 / B204 / B304 / B308 / A104 / A303 / C303 / D106 …）对应的直播间链接；
   - 教室缺链接时明确提示，该场次自动跳过。

4. **安静的自动化实现**
   - 通过 Edge DevTools Protocol（CDP）在后台操作，**不抢焦点、不弹前台窗口**；
   - 签到键盘输入走 Vue 组件事件（`$emit('press')`），绕过虚拟键盘对真实鼠标点击不响应的问题。

## 🚀 使用

解压后有三个入口（`.bat`）：

```
1-启动按课表自动监听与签到.bat    ← 日常全自动挂机
2-打开图形界面(手动配置模式).bat  ← 手动输入直播间链接即时监听
3-管理课程与教室链接.bat          ← 排课表 & 维护教室链接
```

首次运行若本地无登录态，会弹出浙财大扫码登录页，扫码一次即可（登录态持久保存在 `userdata\`，之后免重复扫码）。

## 📁 结构与数据隔离

```
ZUFE_AutoLiveSign\
├─ 1-启动按课表自动监听与签到.bat
├─ 2-打开图形界面(手动配置模式).bat
├─ 3-管理课程与教室链接.bat
├─ start.py                  ← 界面入口（源码）
├─ *.pyd                     ← 核心逻辑（已编译为二进制）
├─ *.mjs                     ← Edge CDP 驱动脚本
├─ rooms.json                ← 教室 ↔ 直播间链接（公共数据）
├─ runtime\                  ← 内置 Python 3.13 + Node 运行时
├─ userdata\                 ← 个人数据（首次运行生成：账号、课表、登录态）
└─ logs\                     ← 运行日志
```

**个人数据全部隔离在 `userdata\`**：把它和 `logs\` 删掉再分享，账号密码、个人课表、Edge 登录 Cookie 都不会外泄，公共教室链接（`rooms.json`）则随包保留。
