### 🆕 v1.8 更新

| 修复 | 说明 |
| :--- | :--- |
| 🔐 登录态误判 | 之前只看 `HTTP 200` 就算“已登录”，但会话失效后页面会跳到 `cas.zufe.edu.cn`，那里同样返回 200，于是被误判成登录有效、一路把码打进一个没登录的页面。现在必须 origin 是 `skl.zufe.edu.cn` 且解析出用户信息才算登录 |
| 🔁 打开签到页自动续期 | 开场打开签到页时若发现登录失效，会先用统一身份认证静默续期；续不上才提示人工登录。之后每 45 分钟复查一次，未登录会明确告警 |
| 📍 重开后「请开启定位!」 | 程序用的 CDP 定位覆盖只对当前连接有效，命令行一退出就失效；签到页重开后坐标变成 0，页面只弹「请开启定位!」而**根本不发签到请求**。现在改为在页面里钉住定位（`navigator.geolocation` shim），并在打字前主动触发一次定位、等坐标落位再输入 |
| ⏳ `doing` 卡死 | 页面 `mySignIn()` 首行是 `if (this.doing) return;`，一次异常后该标志不会复位，之后输满四位毫无反应。现在打字前会复位它 |
| 🧾 记录真实请求与响应 | `logs/签到输入记录.log` 现在会记下**该次签到的完整请求 URL 和服务器响应体**；若压根没发出请求，也会注明（多半是被定位或 doing 拦住） |
| 🔎 失败定性 | 平台连“码不存在”都回 401，和“未登录”的 401 混在一起。失败后会再探一次登录态，明确区分「登录失效」与「码被判定无效」 |

### 🆕 v1.7 更新

| 变化 | 说明 |
| :--- | :--- |
| 🩺 字幕停滞自愈 | 超星 `live-ts` 在签名直播地址过期或服务端重启会话后会**一直返回 200 + 空数组**，不报错也不来新字幕（10-26 那节课从 10:11 一路空转到 12:30 就是这情况）。现在只要 **2 分钟**没有新字幕就自动重建直播间会话；再 2 分钟仍空白则清掉本地游标、从当前直播窗口重新同步（已收字幕按 id 去重，不会重复记录或重复签到） |
| 📝 签到输入流水 | 新增 `logs/签到输入记录.log`：**每次真正把四位数字打进签到页**都会追加一行，含时间、教室、speechId、验证码、浏览器耗时 |
| 📍 定位自检 | 主界面新增【📍 定位自检】；打开签到页时自动打印「浏览器定位权限 / 坐标来源（真实 or 覆盖）/ 页面 valided 是否已认可」。真实定位拿不到时会提示去开 Windows 定位服务 |
| 📧 邮件通知默认关闭 | `userdata/timetable.json` 的 `email.to` 置空后不再创建 Mailer、不再调用 `agently-cli`，日志也不会再出现「邮件发 XXXX」。需要提醒时把邮箱填回 `to` 即可 |
| 🔎 措辞与心跳 | 延迟行由「平板输入」改为「浏览器输入」（签到从来都是走 Edge，旧文案有误导）；心跳行加上「已安静 N 秒」，一眼看出字幕是否还在流动 |
| 🏷️ 版本号 | 窗口标题不再写死 v1.0，启动首屏打印「版本 / 签到引擎 / 程序目录」，便于确认跑的是哪一份 |

## ✨ 功能

1. **按课表全自动守候**
   - 每节课开始前自动在后台拉起 Edge 签到页准备；
   - 自动接入该教室对应的智慧教室直播间，实时抓取课堂语音字幕；
   - 字幕中出现 4 位签到码候选时，毫秒级自动在后台完成签到；
   - 上课期间每 45 分钟自动刷新保活签到页，下课后自动收尾待机。

2. **可视化手动模式**
   - 粘贴任意教室的超星直播间链接 → 点【▶ 开始监听此直播间】→ 界面立即滚动显示该课堂实时字幕；
   - 一键【检查登录认证】【退出认证(清空登录)】【测试输入 1234】。

3. **课表与教室链接管理**
   - 内置浙财标准作息（第 1–14 节），可直接按节次排课；
   - 维护各教室（9107 / B204 / B304 / B308 / A104 / A303 / C303 / D106 …）对应的直播间链接；
   - 教室缺链接时明确提示，该场次自动跳过。

4. **安静的自动化实现**
   - 通过 Edge DevTools Protocol（CDP）在后台操作，**不抢焦点、不弹前台窗口**；
   - 签到键盘输入走 Vue 组件事件（`$emit('press')`），绕过虚拟键盘对真实鼠标点击不响应的问题。

## 🚀 使用

解压后有三个入口（`.bat`）：

```
1-启动按课表自动监听与签到.bat    ← 日常全自动挂机
2-打开图形界面(手动配置模式).bat  ← 手动输入直播间链接即时监听
3-管理课程与教室链接.bat          ← 排课表 & 维护教室链接
```

首次运行若本地无登录态，会弹出浙财大扫码登录页，扫码一次即可（登录态持久保存在 `userdata\`，之后免重复扫码）。

## 📁 结构与数据隔离

```
ZUFE_AutoLiveSign\
├─ 1-启动按课表自动监听与签到.bat
├─ 2-打开图形界面(手动配置模式).bat
├─ 3-管理课程与教室链接.bat
├─ start.py                  ← 界面入口（源码）
├─ *.pyd                     ← 核心逻辑（已编译为二进制）
├─ *.mjs                     ← Edge CDP 驱动脚本
├─ rooms.json                ← 教室 ↔ 直播间链接（公共数据）
├─ runtime\                  ← 内置 Python 3.13 + Node 运行时
├─ userdata\                 ← 个人数据（首次运行生成：账号、课表、登录态）
└─ logs\                     ← 运行日志
```

**个人数据全部隔离在 `userdata\`**：把它和 `logs\` 删掉再分享，账号密码、个人课表、Edge 登录 Cookie 都不会外泄，公共教室链接（`rooms.json`）则随包保留。
