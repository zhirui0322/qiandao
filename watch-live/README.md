# 课堂实况直播（单窗口播放器）

> 点一下，弹出一个播放窗口看**当前这节课**的教室画面，关掉就结束。
> 不常驻、不轮询、不判断有没有课——只在启动那一下看一次课表。

属于 [ZUFE_AutoLiveSign](https://github.com/zhirui0322/qiandao) 的配套小工具，可以单独使用。

---

## 为什么不用浏览器播

超星的直播间页面在部分场次会把播放源写成 `no_source.m3u8`（服务器没给播放源），于是页面、手机端都会报「直播已结束 / 网络连接不稳定」。但教室的摄像头其实一直在推流——只要绕过播放器，直接拉 `live.flv` 就能看。

试过的方案：

| 方案 | 结果 |
| :--- | :--- |
| 超星页面播放器 | 播放源 no_source，必黑屏 |
| 浏览器 + flv.js / MSE | MSE 挂上了，但拿不到数据 |
| 浏览器 + fMP4 直连 | 能播，但一次只服务一个连接，多开互挤 |
| **ffplay 窗口** | ✅ 稳定、流畅、有声音，延迟 1 秒左右 |

## 用法

双击 **`看直播.bat`** 就行。

### 它做什么、不做什么

| 行为 | 说明 |
| :--- | :--- |
| **只开一个窗口** | 默认 `main`（教室摄像头）。投影要单独指定：`--channel ppt` |
| **不常驻后台** | 没有监视线程，不会一直在后台判断“现在有没有课” |
| **只看一次课表** | 启动那一刻判断当前是哪节课、哪个教室，然后直接开窗口 |
| **关掉就结束** | 播放器窗口一关，脚本就退出，不留进程 |
| **没课不弹窗** | 打印「现在没有课」+ 下一节课的时间，然后直接退出 |

### 命令行

```bash
python watch_live.py                    # 当前这节课的教室摄像头（默认，只开一个窗口）
python watch_live.py --channel ppt      # 改看投影 / 大屏
python watch_live.py --channel other    # 其他画面（如果这个教室有）
python watch_live.py --room 9107        # 指定教室，不走课表
python watch_live.py --mute             # 静音
python watch_live.py --test-time 18:35  # 只问“这个时间该看哪个教室”，不弹窗口
```

### 想同时看两路怎么办

开两个终端各跑一条就行——它刻意一次只开一个窗口，是为了避免“点一下弹出一堆播放器”：

```bash
# 终端 1
python watch_live.py
# 终端 2
python watch_live.py --channel ppt
```

### 参数

| 参数 | 默认 | 说明 |
| :--- | :--- | :--- |
| `--room` | 按课表取 | 指定教室号，跳过课表判断 |
| `--channel` | `main` | `main` 摄像头 / `ppt` 投影 / `other` 其他 |
| `--mute` | 关 | 静音 |
| `--test-time` | - | 调试用：按 `HH:MM` 做一次课表判断后退出 |

### 典型输出

```text
正在打开：A104 高效能沟通 - 教室摄像头
关掉播放窗口就结束。
```

没课的时候：

```text
现在没有课。下一节是星期三 15:20 D206 国学经典，到点再点一次就行。
想临时看某个教室：python watch_live.py --room 9107
```

## 需要的两个文件

放在 `watch-live` 目录（或与主程序同目录）下：

**`rooms.json`** —— 教室 → 直播间链接：

```json
{ "9107": ["https://psp-zelda.chaoxing.com/vri-zelda/mobile_live?speechid=..&enc=..&pid=..&warning=false"] }
```

**`userdata/pid.txt`** —— 一行你的 `pid`（链接里那段身份标识）。如果链接本身已经带了 `pid`，这个文件可以不建。

## 常见问题

**为什么只弹一个窗口，投影呢？**
一次只开一个是有意的——点一下弹一堆播放器反而挡屏幕。要投影就再跑一条 `--channel ppt`。

**打开就提示「这个教室现在可能没在推流」**
说明当前没课，或者设备关机了。换 `--channel ppt` 再试一次。

**没有课的时候点开会怎样**
会打印「现在没有课」和下一节课的时间，不会弹窗口。

**窗口一闪就没**
多半是 ffplay 拉流失败（404）。先确认是不是在上课时间。

**能不能让它一直挂着，下课自动换教室？**
不行，这版刻意去掉了常驻逻辑。需要换教室就再点一次 bat。
